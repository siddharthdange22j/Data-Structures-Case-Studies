# Data-Structures-Case-Studies

## Overview
This repository contains seven practical case studies demonstrating the use of fundamental data structures and algorithms in real-world-inspired scenarios. Each case study includes its problem statement, objectives, data structures, working principle, example, complexity analysis, applications, advantages, limitations, conclusion, source code, and sample output.

## Case Studies
1. **E-Commerce Product Sorting** — Divide and Conquer and Merge Sort.
2. **Google Calendar Event Scheduling** — Greedy Activity Selection.
3. **Social Network Friendship Management** — Graph and Adjacency Matrix.
4. **Stack and Queue Operations Using Linked Lists** — LIFO and FIFO.
5. **Dictionary Application Using Hash Tables** — Collision resolution with separate chaining.
6. **GPS / Navigation System Using a Weighted Graph** — Dijkstra's shortest-path algorithm.
7. **ZIP/GZIP-Style Compression Demonstration** — Huffman coding.

## Repository Structure
Every case-study folder contains a `README.md`, a Python source file, and an `output.txt` file with sample output.

## Requirements
- Python 3
- No third-party Python packages are required for these examples.

## How to Run
1. Download or clone this repository.
2. Open a terminal.
3. Change into the case-study folder you want to run.
4. Run the Python file listed in that folder's README. For example:

```bash
python merge_sort.py
```

Use the corresponding filename for the other case studies.

## Educational Scope
These programs are demonstrations for learning and practical work. The calendar project is not connected to the Google Calendar service, the GPS project does not use live map or traffic data, and the Huffman project demonstrates an algorithm rather than creating a standards-compliant ZIP/GZIP archive.
