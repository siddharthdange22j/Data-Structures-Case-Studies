# Data Structures & Algorithms — Case Studies

This repository contains case studies based on Data Structures and Algorithms, focusing on practical applications of algorithmic strategies to real-world problems.

## Case Studies

### 1. E-Commerce Product Sorting
**Strategy:** Divide and Conquer  
**Algorithm:** Merge Sort

An e-commerce platform may contain thousands of products that need to be sorted according to price. This case study demonstrates how Merge Sort can efficiently sort product prices using the Divide and Conquer strategy.

[View Case Study 1](./Case-Study-1-Ecommerce-Sorting/)

### 2. Google Calendar Application
**Strategy:** Greedy Strategy  
**Problem:** Activity Selection

A calendar application may contain multiple events with overlapping timings. This case study demonstrates how the Greedy Strategy can be used to select the maximum number of non-overlapping events.

[View Case Study 2](./Case-Study-2-Google-Calendar/)
